# 01 需求文档

> 项目:GalleryHub —— Obsidian 美术资产画廊插件
> 日期:2026-08-10
> 状态:草案(待用户确认)

## 1. 背景与动机

用户(初言)拥有大量美术类资产,散落在各处,缺乏统一的整合展示方案:

- **美术资产**:AI 生图产物、摄影照片、参考图、视频素材
- **元数据**:AI 生图的 prompt、负向提示词、模型、seed 等生成参数
- **链接**:参考图出处、灵感来源、在线画廊等 URL

### 1.1 已排除的现成方案

| 方案 | 排除原因 |
|---|---|
| Eagle | 数据格式封闭、迁移成本高、付费;无画布式展示 |
| Billfish | 用户实测摄影照片展示不尽人意;3.1.x 仍是网格瀑布流,无画布/策展能力,近年更新无质变 |
| PureRef | 纯项目级参考板,不管理长期库,无法整合 prompt/链接等元数据 |
| Adobe Firefly Boards / Figma Weave | 在线服务,本地资产与数据无法自主掌控 |

**核心结论**:没有任何现成软件能同时覆盖「图片 + 视频 + 链接 + prompt」四类资产,且数据完全留在本地。

### 1.2 选择 Obsidian 插件方案的理由

- 数据(JSON + 资产文件)存放在 Obsidian 仓库内,随 OneDrive 自动同步
- 插件通过 Vault API 直接读写文件,无浏览器沙箱/CORS 限制
- 展示界面与知识库同处一个应用,可与笔记、Canvas 等生态联动
- 数据层为纯文本 + 原始文件,永远可迁移、可脱离插件读取

## 2. 用户目标

1. **统一收纳**:图片、视频、外部链接三类资产集中登记与管理
2. **元数据绑定**:每个资产可挂载 prompt、模型、生成参数、来源、标签、评分、备注
3. **画廊浏览**:网格缩略图墙,支持按标签/类型/评分筛选,按 prompt 全文搜索
4. **画布策展**:无限画布自由摆放资产(类 PureRef / Canvas),同一资产可出现在多个画布
5. **快速复用**:一键复制 prompt;点击卡片查看/编辑全部元数据并写回
6. **自动化入库**:拖入文件自动归档;PNG 内嵌生成参数(A1111 / ComfyUI)自动提取

## 3. 功能需求

### 3.1 V1 —— 画廊骨架(MVP)

- [ ] 自定义视图(ItemView),经 ribbon 图标 / 命令面板打开,占据独立标签页
- [ ] 网格画廊:缩略图墙展示图片资产
- [ ] 筛选器:标签(多选)、类型、评分
- [ ] 搜索:标题 / prompt / 备注 全文匹配
- [ ] 详情面板:点击卡片查看全部元数据,可编辑并写回 gallery.json
- [ ] 一键复制 prompt / 负向提示词
- [ ] 手动新增条目(图片 / 链接)

### 3.2 V2 —— 画布模式

- [ ] 无限画布:拖拽摆放、滚轮缩放、空格平移
- [ ] 多画布(boards)管理:创建 / 重命名 / 删除
- [ ] 同一资产在不同画布上有独立位置与尺寸
- [ ] 链接卡片渲染(标题 + favicon / 缩略图)

### 3.3 V3 —— 自动化

- [ ] 拖文件进视图 → 自动复制到 assets/ → 自动入库
- [ ] 解析 PNG 内嵌元数据(A1111 parameters / ComfyUI workflow),自动填充 prompt / seed / model / steps / cfg
- [ ] 重复检测(基于文件哈希)

## 4. 非功能需求

- **性能**:千级资产量流畅浏览(缩略图懒加载、虚拟滚动视情况引入)
- **数据安全**:写 JSON 前先备份 / 原子写;绝不改动、删除用户资产原件
- **可迁移性**:数据层不依赖插件,gallery.json 结构公开且带版本号
- **主题适配**:遵循 Obsidian CSS 变量,自动适配明暗主题
- **同步友好**:数据文件为格式化 JSON(便于同步差异对比);工程文件不进入仓库

## 5. 待确认事项(Open Questions)

| # | 问题 | 暂定默认值 |

| 1 | 插件/文件夹命名 | `GalleryHub`(仓库内文件夹)、`gallery-hub`(插件 id) |
| 2 | 纳管范围 | 仅管理 `GalleryHub/assets/` 内新资产;`Attachment/` 旧文件按需手动迁移 |
| 3 | 视频支持时机 | V1 即支持视频缩略图 + 点击播放(仓库现存大量 mp4) |

| 5 | 移动端支持 | 暂不承诺,桌面优先 |

## 6. 范围之外(Out of Scope)

- 云端服务、多人协作
- AI 生图功能本身(本插件只管理产物,不调用生图 API)
- 色彩搜索、相似图搜索(Eagle 级 CBIR 功能)
- Obsidian 官方插件市场上架(先自用,后续视情况)
